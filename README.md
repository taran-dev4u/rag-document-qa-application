Production-grade **Retrieval-Augmented Generation (RAG)** Document Q&A Application powered by LangChain, Hugging Face embeddings, Qdrant/FAISS vector search, FastAPI, and Docker.

---

## 🎯 Key Architecture

- **Semantic Document Ingestion:** Overlapping token-aware chunking with metadata tracking.
- **Dense Vector Embeddings:** Integrated with sentence-transformers for 384-dimensional dense semantic search.
- **FastAPI Asynchronous Gateway:** High-throughput streaming endpoints with JWT authentication and Prometheus latency monitoring.
- **Dockerized Microservice:** Production containerization with multi-stage Docker build.
